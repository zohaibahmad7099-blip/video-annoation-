# Video Annotation Tool

A video-review and annotation tool for labelling persons' behaviour for the **Stage A classifier**.

The annotation workflow uses reference tracks generated by the YOLO11m tracking pipeline. Reviewers inspect the video, associate detected tracks with people, label behaviour and visibility over time, and record events. Labels are written to a JSON file for each video.

For the detailed behaviour definitions and annotation policy, see **[`docs/LABELLING_GUIDE.md`](docs/LABELLING_GUIDE.md)**.

## 2. Annotation workflow

The annotation script reads the reference tracks for a video from:

```text
outputs/extract/yolo11m_10hz/<video_name>_tracks.csv
```

It writes the annotation file to:

```text
labels/<video_key>.json
```

The label JSON is updated after every annotation change.

### Run the annotator

From the repository root, run:

```bash
python annotate.py --video "159 Back Cooler_05" --reviewer Zohaib
```

Replace the video name and reviewer value as appropriate.

**Arguments**

| Argument | Description |
|---|---|
| `--video` | Video name used to locate the reference tracks and identify the annotation output |
| `--reviewer` | Reviewer name recorded for the annotation session |

### Expected input and output locations

```text
outputs/
└── extract/
    └── yolo11m_10hz/
        └── <video_name>_tracks.csv

labels/
└── <video_key>.json
```

Make sure the reference track CSV exists at the expected location before starting annotation.

## 3. Keyboard shortcuts

The following shortcuts are available in `annotate.py`.

### Video navigation

| Key | Action |
|---|---|
| `SPACE` | Play / pause |
| `D` / `A` | Move forward / backward by 1 frame |
| `L` / `J` | Move forward / backward by 2 seconds |
| `K` / `H` | Move forward / backward by 10 seconds |

### Person and track management

| Key / action | Action |
|---|---|
| Click a box | Select a track |
| `N` | Create a new person from the selected track |
| `G` | Link the selected track to a person |
| `U` | Unlink the selected track |
| `I` | Set the actor ID |
| `T` | Toggle staff status |

### Annotation range

| Key | Action |
|---|---|
| `S` | Set the start mark at the current playhead |

When a label key is pressed after setting a start mark, that label covers the interval from the marked frame to the current playhead.

### Behaviour / phase labels

| Key | Label |
|---|---|
| `1` | Normal |
| `2` | Inspect |
| `3` | Pick — purchase, no event |
| `4` | Pick — current event |
| `5` | Suspicious — current event |
| `6` | Basket |
| `7` | Return |
| `0` | Unknown |

Use the behaviour definitions in [`docs/LABELLING_GUIDE.md`](docs/LABELLING_GUIDE.md) when deciding which label applies.

### Visibility labels

| Key | Label |
|---|---|
| `V` | Visible |
| `O` | Hands occluded |
| `B` | Body occluded |

### Event annotation

| Key | Action |
|---|---|
| `E` | Create a new event |
| `W` | Cycle the current event |
| `M` | Mark a missed event (no track) over the selected range |

### Fill, save, undo and reset

| Key | Action |
|---|---|
| `F` | Fill the person's unlabelled time with **Normal + Visible** |
| `Y` | Fill the person's unlabelled time with **Normal + Hands Occluded** |
| `C` | Save labels |
| `X` | Undo one action |
| `Z` | Reset the selected person's labels |
| `R` | Reset all labels |
| `Q` / `ESC` | Quit |

> **Important:** `Z` resets labels for the selected person, while `R` resets all labels. Use these reset commands carefully.

## 4. Validate annotation labels

After annotation, run the label checker from the repository root:

### Windows (PowerShell / Command Prompt)

```bash
python -m label_check --labels ".\labels"
```

### Linux / macOS

```bash
python -m label_check --labels "./labels"
```

The command points the checker to the `labels` directory. Review the terminal output and address any reported issues before using the annotations downstream.

## 5. Recommended review sequence

1. Confirm that the reference track CSV exists under `outputs/extract/yolo11m_10hz/`.
2. Start `annotate.py` with the correct video name and reviewer.
3. Play or navigate through the video and inspect the detected person tracks.
4. Select tracks and create or link them to the correct person.
5. Set actor ID and staff status where applicable.
6. Mark the relevant time range and apply behaviour and visibility labels.
7. Create and associate events where required. Use the missed-event shortcut when an event has no corresponding track.
8. Review the person's timeline and fill unlabelled time only when the applicable shortcut is appropriate.
9. Save the labels and repeat the review for the remaining people and events.
10. Run `label_check.py` against the labels directory and review its output.

Follow the labelling guide for the actual annotation criteria; this sequence is an operational checklist, not a replacement for the guide.

## 6. Output

The primary annotation output is one JSON file per video:

```text
labels/<video_key>.json
```

Keep the generated JSON files together in the `labels/` directory so they can be checked as a batch:

```bash
python -m label_check --labels ".\labels"
```

## 7. Important notes

- Run commands from the repository root unless your environment is configured otherwise.
- Use the video name that corresponds to the reference track CSV.
- Do not change the meaning of the behaviour or visibility labels between videos.
- Use the labelling guide as the source of truth for annotation decisions.
- Keep the original reference track CSV files available while reviewing videos.
- Validate the completed labels before passing them to the next stage of the dataset or classifier workflow.
